# Privacy Policy

`AemiProtobuf` is an open-source Foundation-free Protocol Buffers wire engine, Codable coders, and ProtoJSON library for Swift, licensed under the MIT License.

## Data Collection and Telemetry

- **No telemetry or analytics:** `AemiProtobuf` collects, stores, and transmits **zero** telemetry, usage analytics, crash reports, or personal data.
- **No network access:** `AemiProtobuf` performs no outbound network requests and contains no tracking, licensing, or phone-home logic.

## Data Processed Locally

As a compiled Swift library, `AemiProtobuf` processes only the in-memory inputs and local filesystem paths provided directly by the host application or tool that links it.

## GDPR and Enterprise Compliance

`AemiProtobuf` operates strictly within the calling process and transmits no data to external services.
