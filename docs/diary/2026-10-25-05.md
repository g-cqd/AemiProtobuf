# 2026-10-26 — slow paths, gates, and the schema tools

## Slow paths (roadmap A)

Probed in this order, each before a change: packed doubles and fixed-width (37× behind swift-protobuf): fixed, now 1.5× ahead.
Packed varint decode: fixed (592 → 341 µs; the first version, which counted varints byte by byte, was slower, 842 µs, until the count
used a word-at-a-time scan). Probed and left: string encode (three variants, no gain), `Data` borrowing (no gain, slower when small),
declared field count (no growth), varint read versus the kernel (the local loop is 2.2× faster), parallel scaling (the machine, not
the allocator), the ADR-0008 reverse-write claim (now stated as unmeasured). Additive API: `ProtobufEncoder`/`ProtobufDecoder`
overloads for fast-path-only types and for `Codable` fast-path types, chosen at compile time (the dynamic cast costs about 40 ns).
The validator no longer builds a dictionary for small messages. `ComparisonMemory` measures one decode per process.

## Gates (B)

Allocation thresholds now cover the macro and generic coders, packed read and write, the descriptor set, the comparator and the
validator (17 files). Deterministic fuzzing: every one-byte change and prefix of the protoc messages through the macro, generic and
schema decoders, the validator, and damaged `.proto` text. The mutation gate caught real gaps in new code (a symmetric test that
could not tell terminators from continuation bytes; compaction boundaries; the default compressed flag); the core now has 239 viable
mutants; the first full run left 26 survivors, new tests killed 11 of them, and 4 more in `FrameDecoder` (50 of 50 killed when that file
is run alone). The 11 that remain are baselined with a reason: preconditions whose weaker form only widens a check that traps, an
equivalent boundary, and `reserve` calls whose only effect is allocation, which the thresholds watch.

## Schema and streaming (C)

Nested wire validation with name resolution and finding paths (0007); the comparator by number with nested messages and enums (0008);
gRPC and varint-delimited framing with a push parser and an async sequence (0009). Not done: macro `oneof`, maps, unknown-field
preservation and merge; proto2, editions, imports and a printer in the parser; the lazy view; proto JSON; the conformance runner;
NIO and the protoc plugin; reserved ranges and lint.
