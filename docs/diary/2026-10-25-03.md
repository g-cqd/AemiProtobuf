# 2026-10-25 — Schema safety checkpoint

## Build recovery

`WireValidator` exposed `WireLimits` through an internal import. Public import plus an explicitly typed reader closure restored
compilation. Removed the forced error cast; the typed catch already receives `WireError`.

## Rejection tests and repairs

Tests failed before repair for truncated string framing, incorrect UTF-8 offsets, unchecked packed scalars, invalid descriptor
numbers, and payload-relative corruption offsets. Validator now preserves framing errors, validates packed numeric payloads,
rejects duplicate descriptor numbers without a dictionary trap, and caps findings with an explicit incomplete marker.
A mismatched wire type no longer satisfies required-field presence. A corrupted traversal does not report unvisited required
fields as definitely absent. Packed fields do not consume message nesting depth.

Parser tests exposed silent character skipping, wrapping integer arithmetic, unclosed comments/enums, invalid field numbers,
and unbounded message nesting. Lexer now rejects unsupported characters/escapes and arithmetic overflow; parser rejects
unterminated enums and invalid field numbers and bounds source UTF-8 bytes and message nesting. Shared token checks replace
repeated guards. Comparator descriptions now derive from the change kind through one initializer; comparison policy is unchanged.
