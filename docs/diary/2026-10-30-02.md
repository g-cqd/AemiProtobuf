# 2026-10-30 (02) — aemi and AemiJSON move together

AemiJSON `44aed49` pins aemi `5e56014` and AemiRegex `637ffee` (its roadmap 0010), and so do MacFS, ask and TerminalKit.
This package pinned aemi `bfc4f5a` and AemiJSON `1d0e9a2`. Taking AemiJSON's head forces aemi to the same revision, so
both pins moved in one commit: SwiftPM accepts one revision per package in a graph. analyzerkit takes this revision
next (its roadmap 0049 lists the train), and swift-search after it, for AemiJSONRPC.

Checked: the whole suite (366 tests, 8 runs) and the official conformance suite against protoc 36.2's runner, binary and
JSON 5,647 passed and text format 909 passed, 0 failures, the same as before. The benchmarks were not run: the machine
was at a load average of 20 to 140, and AemiJSON's changes since `1d0e9a2` (member hints, a value encoder, coding paths,
AemiJSONRPC) are on its Codable side, which AemiProtobufJSON does not use. That is reasoning, not a measurement.
