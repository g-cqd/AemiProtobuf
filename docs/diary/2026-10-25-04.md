# 2026-10-25 — oneof, a rebuilt Codable layer, and the AemiJSON comparison

## Schema

`oneof` and proto3 `optional` parse to exactly the descriptor `protoc` wrote (`oneof.proto` fixture, equality test) and
re-encode to the bytes `protoc` wrote. The explicit `LABEL_OPTIONAL` is now written, as protoc does. A `oneof_index` outside the
message's oneofs is refused (`DescriptorError`). Parsing the three-field fixture costs 21 allocations, up from 19 (threshold
raised, queued in roadmap 0017). Dolly baseline regenerated: the descriptor read/write files share one field-table shape.

## Codable: probe, then rebuild

The comparison package's first run found the umbrella's generic path did not round-trip an ordinary list of nested records. Cause
(ADR-0010): arrays of messages and nested containers trapped or were dropped, optional presence was lost, depth reset at each
level, `try?` swallowed malformed input, and the scalar `AemiProtoFast*` conformances made `encode(5)` write the byte `05`.
Rebuilt with a per-message field index and begin/end message support in the core. Evidence: `protoc --encode` bytes match in
both directions; 10 adversarial tests (merge, last wins, unknown fields, packed/unpacked mix, wrong wire type, range overflow, bad
UTF-8, truncation, 3,000 random buffers, depth limit, size limit, dictionary, top-level scalar); core tests for `beginMessage`,
`endMessage`, `abandonMessage`, `withReader(over:in:depth:)`, `readPayloadRange`, `string(from:in:)`.
The first dispatch for repeated elements was a chain of `as?`; comparing metatype identity took 100,000 integers from 11.4 to
4.2 ms to encode (one measurement each). Still slow against the fast path: roadmap 0018.

## Comparison

`Benchmarks/Comparison`, `Scripts/compare.sh`, results in `docs/research/2026-10-25-aemijson-vs-aemiprotobuf.md`. 143 benchmarks,
every codec round-trip checked and `protoc --decode` run over the protobuf bytes first. The two full runs (first with the
unoptimised Codable dispatch) agree to a median of 0.5 % on the 119 unchanged rows.

## Gates at the end of this entry

`Scripts/quality.sh fast`, `test` (debug and release: 20 umbrella, 33 schema, 26 repository, 59 core), `model`, and the seven
allocation thresholds pass. The Aemi pin moved to AemiJSON's current revision (the comparison needs one revision for both).
Mutation: the gate had silently started to mutate the umbrella and schema sources with the core's tests (624 mutants, 467 with no coverage); it is scoped back to `Sources/AemiProtobufCore`: 116 viable mutants, 112 killed, 4 baselined (the `reserveCapacity` and `keepingCapacity` performance mutants that the allocation gate kills, and two `&&` to `||` in preconditions that only widen a check that traps). A failed group skip leaving state behind was a real gap and is now tested. Not done: mutation coverage of the umbrella and schema targets, CI/Linux, swift-protobuf in the comparison.

## Addendum: the macro, and swift-protobuf in the comparison

`@ProtoMessage` generates the fast path and `Codable` (ADR-0011, roadmap 0005): 10 macro tests, an oracle of every kind against
`protoc --encode`, byte-for-byte both ways. The comparison's protobuf types are now macro types. swift-protobuf 1.39.0 joined it
with code from its own plugin; its bytes equal ours at every size. Findings: ours is faster on records (encode 2.2x, decode 1.26x),
slower on bulk packed numbers and string encode (doubles encode 37x, an append-per-byte writer: roadmap 0019). The research note
holds the tables. Mutation coverage of the macro target is not done.
